Features

Everything a virtual cable does, none of the cleanup.

01

Mirror to as many devices as you like

Add and remove destinations one at a time. Analogue, USB, HDMI and Bluetooth all work together, and everything else keeps playing while you do it.

02

Nothing gets left behind

Off really means off: no leftover virtual device, no changed default output, no service quietly running in the background.

03

Independent volume per device

Everyone sets their own level. Turning the speakers down doesn't touch the headphones next to them.

04

Different sample rates? No problem

A 192 kHz output can mirror to a 48 kHz headset. Mirrik converts on the fly so you don't have to think about it.

05

Survives you changing things

Switch your main output mid-session and the mirror follows. Unplug a destination and its row stays, waiting. With the window open it rejoins by itself; otherwise the next window or command picks it up.

06

Keyboard-driven, plus a real CLI

The window runs entirely from the keyboard. Everything it can do is also a command, with --json on anything that reports something.

How it works

No virtual device, on either platform.

On Windows, a WASAPI loopback client captures whatever the default output is playing and pushes copies to each destination. On Linux, a PipeWire loopback taps the monitor of your current sink. Neither side ever creates a device of its own. That's not an implementation detail, it's the whole point. Each mirrored destination is kept alive by its own small background process, so if that process ever dies, that destination is simply gone. Nothing can outlive a crash.

1

Summon the window

One hotkey opens it, centred, ready for the keyboard: no mouse required from here on.

2

Pick your devices

↑ ↓ move the focus, Enter adds or removes, ← → nudge a fader in 5% steps, and 1–9 toggle a device directly. Had a set on last time? Space takes it back.

3

Close whenever

Esc closes the window and the mirror carries on. x stops it, everywhere at once.

Install guide

Pick your platform.

01Check you have PipeWire
pactl info | grep 'Server Name'

Needs to say PipeWire. Plain PulseAudio is refused on purpose, since a crash there would leave a loopback behind for good.

02Clone and run the guided installer
git clone https://github.com/Kris-023/mirrik.git
cd mirrik
./install.sh

No root needed. It checks for the four required tools first and figures out the right key binding for your compositor or desktop.

03Changed your mind?
./install.sh
# then pick: 2) Show me how to remove it

There is no --uninstall flag. The script prints the commands, you run them. It kept track of what it wrote, so the list matches your install and nothing gets missed.

01Download and check the release
Get-FileHash -Algorithm SHA256 mirrik-0.1.1-windows-x86_64.zip

Grab the latest release and compare the hash against the SHA256SUMS file published beside it. That proves the download arrived intact.

02Unpack it, then run the guided installer
powershell -ExecutionPolicy Bypass -File install.ps1

Unzip it first and run this from inside that folder. No admin rights. It adds both programs to PATH and offers a Start-menu shortcut with a hotkey.

03Expect a SmartScreen prompt

Choose More info, then Run anyway. Mirrik isn’t code-signed, so Windows warns about it either way. The source is here if you’d rather build it yourself.

04Changed your mind?
powershell -ExecutionPolicy Bypass -File install.ps1 -Uninstall

Shows everything it found before removing any of it.

01Clone
git clone https://github.com/Kris-023/mirrik.git
cd mirrik
02Build
cargo build --release

Needs Rust 1.95 or newer. That floor comes from egui/eframe, not from Mirrik itself.

03Install the binaries
install -Dm755 target/release/mirrik     ~/.local/bin/mirrik
install -Dm755 target/release/mirrik-gui ~/.local/bin/mirrik-gui

On Windows, just put mirrik.exe and mirrik-gui.exe somewhere permanent instead.
